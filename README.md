# 我的秋招邮件助手（轻量版 v1.0）

基于 tokunouu045-byte/job-mail-assistant 的 MIT 开源项目修改，保留原作者许可。原始参考：https://github.com/tokunouu045-byte/job-mail-assistant ，参考提交 ae1c4d86d57c4b5a4b523fd894a34539d6354847。

## 新增功能
- 2027 校招 / 实习切换；校招模板不套用实习出勤条件。
- 海外营销 / KOL、品牌 / 整合营销、外贸 / 海外销售三套独立资料；填写并保存后切换使用。
- 添加、选择、删除多份 PDF 简历，每份上限 5MB。
- QQ 和 163 网易邮箱草稿填写；最终发送由用户完成。
- 公司、岗位、下一步分类、记录状态、备注；下一步可继续修改。
- 导出 Excel 可打开的 UTF-8 CSV，“下一步”位于“公司”之后。
- 不把草稿填写成功自动当作发送成功。

## 安装
1. 解压此包，保留整个目录。
2. 打开 Edge 的 edge://extensions/（Chrome 可尝试 chrome://extensions/）。
3. 开启开发人员模式，点击“加载解压缩的扩展”。
4. 选择 extension 文件夹，其中直接包含 manifest.json。
5. 固定扩展到工具栏。首次打开“个人资料与 AI 设置”，录入真实资料；每个方向分别保存。

## 使用
1. 选择校招或实习、岗位方向，输入公司与岗位。
2. 打开招聘页面读取文字，或直接粘贴 JD。
3. 无需 API：点击复制资料与要求到 ChatGPT，可手动附招聘图片，再将完整回复导入。
4. API 可选，使用自己账户可用的模型；密钥只存浏览器会话。
5. 添加并选择合适简历；核对邮箱、主题、正文、附件，勾选审核。
6. 选择 QQ 或 163，打开邮箱填写；已有写信页时，切换到该页后点击“填入当前写信页”。
7. 检查收件地址已确认、附件上传成功，再手动发送。
8. 在投递记录选择“已手动发送”并保存；下一步可选待投递、待笔试、待面试、待反馈、待跟进、已获Offer、已结束。

163 为首版适配：使用输入框、标签和编辑器定位，支持点选收件人及复制备用。邮箱网页改版、跨域编辑器或上传组件可能导致自动填写失败；未在真实登录账户完成验证。失败时复制正文、主题和收件人，并手动添加简历。助手不会点击发送。

## 轻量包与隐私
本包不包含原项目体积较大的 Tesseract 离线 OCR。招聘图片可直接附在 ChatGPT，或配置 OpenAI API 识图；DeepSeek 模式用于文字生成。
资料、简历和记录保存在本机扩展存储，未内置真实个人资料。PDF 不传给 AI。只有选择 API 时，招聘文字和个人资料（或识图图片）才发送给所选服务。
扩展不读取 ChatGPT 对话，不保存邮箱密码，没有运营服务器或统计脚本。unlimitedStorage 用于多份 PDF 在本机存储。

## 上传自己的 GitHub
新建空仓库，将此目录中的 LICENSE、README.md、package.json、extension 和 tests 等源码上传。不要上传真实简历、API 密钥、投递 CSV 或浏览器数据。GitHub 用于保存源码与下载包；这个扩展不是 GitHub Pages 网页。
